# wfview for Android 操作説明書

Android タブレット向けにタッチ操作へ最適化した **wfview**（ネットワーク接続専用）の操作説明書です。
Icom LAN 対応リグ本体（IC-705 / IC-9700 / IC-7610 など）、または Raspberry Pi / PC 上で動作する **wfserver** に Wi-Fi 経由で接続し、リグを遠隔操作します。

- **対象端末**: Android タブレット／スマートフォン（arm64-v8a）。画面サイズ・解像度・縦横比には**自動で追従**します（レスポンシブ表示）
- **画面向き**: 横向き（ランドスケープ）全画面
- **接続方式**: ネットワーク（Icom LAN プロトコル）のみ。USB／シリアル接続には非対応です。
- **ベース**: デスクトップ版 wfview のフル機能 UI を Android タブレットの画面とタッチ操作に合わせて調整したものです。デスクトップ版の機能（レピータ／スプリット、メモリー管理、CW 送信、送受信音声処理など）がほぼそのまま使えます。

## 1. インストールと有効期限

- 本アプリはストア非配布のため、APK（`android-build-debug.apk`）を **adb install** などでインストールします（手順は `ANDROID_BUILD_NOTES_MAC.md` 参照）。
- 画面は**横向き（ランドスケープ）固定**です。
- リグ／wfserver と同じ Wi-Fi（ローカルネットワーク）に接続してください。

## 2. 起動と接続（接続プロファイル）

### 2-1. 接続先の設定

1. 画面下部の **Settings** をタップして設定画面を開きます。
2. 左側のカテゴリで **Radio Access** を選び、次を入力します。
   - **Network（Enable LAN）**: ネットワーク接続を有効にします（iPad 版は常にこちらを使います）。
   - **Hostname**: リグ本体または wfserver の IP アドレス／ホスト名（例: `192.168.1.20`）
   - **Control Port**: 制御用ポート番号（既定 `50001`）
   - **Username / Password**: wfserver（またはリグ本体の Network 設定）で決めた認証情報
   - **RX / TX Audio**: 受信・送信音声のコーデックとサンプルレート。通常は既定のままで動作します。音が途切れる回線では低いレートやより圧縮率の高いコーデック（Opus など）を試してください。
3. **Save Settings** で保存します。

設定画面には他に **User Interface**（配色・周波数単位など）、**Radio Settings**、**Radio Server**、**External Control**、**DX Cluster**、**Experimental** のカテゴリがあります。通常の運用で触るのは Radio Access と User Interface だけです。

### 2-2. 接続プロファイル（複数の接続先の使い分け）

- **Connection Profile** 欄に名前（例: `自宅7300` / `山小屋wfserver`）を入力して **Save** をタップすると、現在のリグ・LAN・音声・ログイン設定一式が名前付きで保存されます。
- プルダウンから既存プロファイルを選ぶと、保存済みの値が設定欄へ復元されます。
- **Delete** で選択中のプロファイルを削除します。
- **Connect** を押した時点で、選択中のプロファイルが再読込されてから接続が始まります。「プロファイルを選ぶ → Connect」だけで接続先を切り替えられます。

### 2-3. 接続と切断

- **「← 戻る」** で設定画面を閉じ、**Connect** をタップすると接続を開始します。
- 接続が確立するとボタンが **Disconnect from Radio** に変わり、リグ名がステータスバーに表示され、リグの機能に応じた操作ボタンが画面に現れます。
- 切断するときは同じボタンをタップします。

## 4. 周波数の操作

周波数の合わせ方は 4 通りあります。状況で使い分けてください。

### 4-1. ウォーターフォールをタップ（いちばん手軽）

聞きたい信号の縦すじを**シングルタップ**すると、その周波数へ即座に同調します。ダブルタップでも同調します。おおまかに合わせてから、ダイアルで追い込むのが基本です。

### 4-2. 周波数表示の桁タップ ＋ 周波数ダイアル（精密に合わせる）

1. 周波数表示の**合わせたい桁をタップ**します。その桁が**同調ステップ**として選択されます（周波数自体は変わりません）。
2. **周波数ダイアル**を回すと、選んだステップで周波数が増減します。
   - 例: 1 kHz の桁をタップ → ダイアル 1 ステップ＝1 kHz
   - SSB の同調は 100 Hz〜1 kHz、CW は 10〜100 Hz の桁が使いやすい目安です。
3. 周波数表示の右の **▼／▲ ボタン**でも、選んだステップで 1 ステップずつ下げ／上げできます（**長押しで連続**）。
4. さらに細かく合わせたいときは **Fine** をオンにします。ダイアルが一時的に **1 Hz ステップ**になり、オフにすると元のステップへ戻ります。

### 4-3. 直接入力（Freq）／バンド選択（Bands）

- **Freq**: テンキー画面で周波数を数字入力します。目的の周波数が分かっているときに最速です。テンキーの **Back** キーは入力を 1 桁削除します（メイン画面へ戻るのは左上の「← 戻る」）。
- **Bands**: バンドボタン（3.5 / 7 / 14 / 21 / 28 / 50 MHz…）でバンドを一気に移動します。バンドをタップすると画面は自動的に閉じてメイン画面へ戻ります。

### 4-4. Lock と RIT

- **Lock**: 周波数をロックし、誤タッチによる同調ずれを防ぎます。ロック中は **▼／▲ ステップボタンもグレーアウト**して押せません。ダイアルやタップ同調が効かなくなったら、まず Lock を確認してください。
- **送信中は自動的に周波数ロック**になります（送信中の誤タッチで周波数が飛ぶのを防ぐため）。受信に戻ると送信前の状態（Lock オン／オフ）に復帰します。
- **RIT**: 送信周波数は変えずに**受信周波数だけ**を微調整します（±で数百 Hz 程度）。相手が少しずれて呼んできたときに、こちらの送信を動かさずに聞きやすくできます。RIT ダイアルの横のチェックで有効／無効を切り替えます。

## 5. スペクトラム／ウォーターフォール（スコープ）

### 5-1. 見方

- **スペクトラム（上段）**: 横軸＝周波数、縦軸＝信号強度。山（ピーク）が信号です。
- **ウォーターフォール（下段）**: 時間の流れを色で表示します（新しい表示が上から流れます）。明るい縦すじほど強い信号です。空き周波数や信号の出方が一目で分かります。
- アマチュアバンドの範囲はバンドインジケーターで示されます。

### 5-2. 操作

| 操作 | 動作 |
|------|------|
| ウォーターフォールをタップ | その周波数へ同調（4-1 参照） |
| **切離し** | スコープを別画面へ切り離して大きく表示。**戻す** で元に戻ります（メイン画面のサイズは保たれます） |
| スパン／表示モード | 表示範囲（±kHz）や Center／Fixed 表示を切替 |
| **WF スライダー** | ウォーターフォールの色レベル（floor）を調整。ノイズで画面が明るすぎるときは上げ、弱い信号まで見たいときは下げます |
| モード／フィルター | スコープ周辺のドロップダウンで運用モード（USB/LSB/CW…）と受信フィルター（FIL1/2/3）を選択 |

- 対応機種（IC-7610 / IC-9700 など）では **Dual Watch**、**Main/Sub** スコープ切替、**Swap**（Main⇔Sub 入替）、**Main=Sub** の各ボタンが表示されます。

---

## 6. メーター（S / Tx レベル）

- **S メーター**: 受信信号の強さです。S9 を超える強力な信号は +10dB/+20dB… と表示されます。
- **SWR メーター**: 送信中のアンテナ整合状態です。**送信終了後も直前の測定値を保持**するので、送信し終えてから落ち着いて確認できます。
  - 目安: **1.5 以下＝良好**、2 前後＝許容範囲、**3 以上＝要調整**（ATU でのチューニングやアンテナの点検を）。
- メーターの種別は設定（User Interface）で変更できますが、iPad 版は S＋SWR の組み合わせを標準にしています。

## 7. 操作ボタン列（電源・送信・TUNE など）

| ボタン | 動作 |
|--------|------|
| **電源ON / 電源OFF** | リグ本体の電源を入／切します。誤操作防止のため**ダブルタップで実行**します（1 回目のタップで最下段に案内が出て、2.5 秒以内の 2 回目で実行）。wfserver 経由でも、リグが対応していればリモートで電源投入できます |
| **送信**（緑色の大きなボタン） | PTT です。タップした瞬間に「**送信中**」表示に切り替わり送信開始、もう一度タップで受信へ戻ります。送信中は S メーター下の **Tx(dBfs) メーター**で自分の変調レベルを確認できます（-12〜-6 dBfs が目安） |
| **TUNE** | 内蔵 ATU のチューニングサイクルを開始します。SWR が高いときに使います。リグ側の ATU 機能が OFF のときは「ATU調整失敗（無線機のATUがOFF）」と表示されるので、Other Controls の **Tune（Enable ATU）** チェックを入れてから再実行してください |
| **CW** | CW 送信画面を開きます（→ 12 章） |
| **Rpt/Split** | レピータ／スプリット設定画面を開きます（→ 10 章） |
| **Split** | スプリット ON/OFF のトグル（IC-7610 / IC-785x など対応機種のみ表示） |
| **Memories** | メモリー管理画面を開きます（→ 11 章） |
| **終了**（最下段右端） | アプリを終了します。電源ボタンと同じく**ダブルタップで実行**（未保存の設定は自動保存されます） |

> **送信前のチェック**: 周波数（バンドプランの範囲内か）・モード・出力・アンテナ（SWR）を確認してから送信ボタンを押してください。

## 8. 受信を整える（Other Controls・Preamp/Att・スライダー）

### 8-1. Other Controls（受信・送信のオン／オフ機能）

| スイッチ | 機能 | 使いどころ |
|----------|------|-----------|
| **NB**（ノイズブランカー） | パルス性ノイズの除去 | 車のイグニッション、電気柵などの「パチパチ」ノイズに |
| **NR**（ノイズリダクション） | ランダムノイズの低減 | 「ザー」というノイズに。かけ過ぎると音がこもります |
| **IP+** | インターセプトポイント改善 | 強力な信号が近接して歪むとき |
| **DIGI-SEL** | デジタルプリセレクター | 近接周波数の強力局によるかぶり対策（対応機のみ） |
| **COMP**（コンプレッサー） | 送信音声の平均電力を上げる | SSB で了解度を稼ぎたいとき。かけ過ぎ注意 |
| **VOX** | 声で自動送信 | ハンズフリー運用。誤動作に注意 |
| **Tune（Enable ATU）** | 内蔵 ATU を経由する／しない | ATU を使うときはオン。TUNE ボタンとセットで使用 |

### 8-2. Preamp/Att（プリアンプ／アッテネーター）

- **Preamp**: 弱い信号を増幅します（OFF / 1 / 2）。ハイバンドの弱い信号に有効。強い信号が多いバンドではオフが無難です。
- **Att**: 強すぎる信号を減衰します。近隣の強力局で受信が歪む・S メーターが振り切れるときに入れます。

### 8-3. Antenna

複数アンテナ端子を持つ機種では、使用するアンテナ（ANT1/ANT2…）を選択できます。**RX Antenna** チェックで受信専用アンテナへの切替も可能です（対応機のみ）。

### 8-4. スライダー

画面には左から **RF / AF / SQ / MOD / TX / Mon / WF** の 7 本が並びます。

| スライダー | 機能 | 目安 |
|-----------|------|------|
| **RF** | 受信 RF ゲイン | 通常は最大。強信号だらけのバンドでは絞るとノイズと混信が減って聞きやすくなります |
| **AF** | 受信音量 | タブレットのスピーカー／接続中のヘッドホンへ出力されます。**Android のメディア音量と連動**します（AF 最大＝端末音量最大）。**起動時は常に 50%** から始まります |
| **SQ** | スケルチ | 無信号時のノイズを消す。FM で特に有効。開き過ぎ（上げ過ぎ）ると弱い信号まで切ってしまいます |
| **MOD**（変調レベル） | 送信変調の深さ。現在の送信音声入力（USB/LAN/Mic など）のレベルを調整します | 接続時は**前回設定した値**（初回は 50%）がリグへ適用されます。送信中も調整できるので、**Mon** で自分の声を聞きながら歪まない位置に合わせてください。上げ過ぎは過変調（歪み・帯域外への広がり）の原因になります |
| **TX** | 送信出力 | 必要最小限の電力で運用するのが基本です |
| **Mon** | 送信音のモニター | 自分の送信音を確認しながら変調レベルや TX Proc を調整するときに |
| **WF** | ウォーターフォールの色レベル | 5-2 参照 |

## 9. ポップアップ画面と「← 戻る」ボタン

すべてのポップアップ画面（設定・バンド選択・Freq・**ログ表示**・**Status（無線機ステータス）**・レピータ／スプリット・メモリー・CW・TX/RX Proc）の**左上に共通の「← 戻る」ボタン**があり、タップするとメイン画面へ戻ります。TX Proc のように縦に長い画面は、指で上下にスクロールできます。

Settings・Status・Log・Bands・Freq・TX Proc・RX Proc・**Rpt/Split・Memories・CW**・**ヘルプ** の各画面は、すべて**メイン画面の中央に重なるオーバーレイ**として開きます。

- 各画面の最上部に幅広の **「← 戻る」** ボタンがあり、タップするとメイン画面へ戻ります。
- ヘルプ画面だけは 2 段階で、章へジャンプした後は「← 目次に戻る」→「← 戻る」の順で戻ります。
- バンド選択はバンドを、Status は無線機を選ぶと**自動的に閉じて**メイン画面へ戻ります（Status はキャンセルでも戻ります）。
- 画面に収まらない内容は、右端の太いスクロールバーをドラッグしてスクロールします（ヘルプ画面は本文の**スワイプでもスクロール**できます）。
- 別のポップアップを開くと、表示中のポップアップは自動的に閉じます。

## 10. レピータ／スプリット設定（Rpt/Split）

**Rpt/Split** ボタンで開きます。上段がレピータ（デュプレックス）、下段がスプリット、右側が VFO 操作です。

### 10-1. レピータ運用（Repeater Duplex）— 主に FM／430・1200 MHz 帯

レピータ（中継局）は「受信と送信が一定のオフセットだけずれた周波数」で運用します。

1. レピータの**出力周波数**（自分が聞く周波数）に同調します。
2. **Dup+ / Dup-** でオフセットの方向を選びます（日本の 430MHz 帯レピータは通常 **Dup-**（−5 MHz）。**Auto** はリグのバンドプランに従い自動設定します）。
3. **Set Offset (MHz)** にオフセット量を入力して設定します。
4. トーンが必要なレピータでは **Set Rpt Tone** で送信トーン（88.5 Hz など）を設定します（対応機のみ）。
5. 送信すると自動的にオフセットぶんずれた周波数で電波が出ます。**Simplex** を選ぶと通常運用に戻ります。

### 10-2. スプリット運用（Split Mode）— 主に HF の DX・パイルアップ

スプリットは「受信と送信を別々の周波数にする」運用です。DX 局が「UP 1」などと指定したときに使います。

1. DX 局の周波数に同調します（VFO A で受信）。
2. **Offset (KHz)** に指定されたオフセット（例: `1`）を入力します。
3. **Split+**（受信＋オフセットで送信）または **Split-**（受信−オフセット）をタップすると、送信 VFO（サブ VFO）が設定され、スプリットがオンになります。
4. **Tx Freq (MHz)** に送信周波数を直接入力して **Set** することもできます。
5. **QuickSplit / AutoTrack** をオンにすると、受信周波数を動かしても送信 VFO がオフセットを保って追従します。
6. 終わったら **Split Off** で解除します。

### 10-3. VFO 操作

**Swap AB**（A⇔B 入替）、**Sel A / Sel B**、**Sel Main / Sel Sub**、**A=B**（B に A をコピー）など、機種に応じた VFO 操作がまとまっています。スプリットの準備（B に送信周波数を作る等）にも使えます。

## 11. メモリー管理（Memories）

**Memories** ボタンで開きます。リグ本体のメモリーチャンネルの閲覧・編集・呼び出しができます。

- **初回の確認ダイアログ**: メモリー機能は実験的機能です。**操作前にリグ本体のフルバックアップ**を取ってください。「Don't ask me again」にチェックすると次回から確認を省略します。
- **グループ選択**: 上部のドロップダウンでメモリーグループを切り替えます。
- **一覧表**: 各チャンネルの周波数・モード・名前などが表形式で表示されます。読み込みには少し時間がかかることがあります。
- **編集**: **Disable Editing** のチェックを外すと表のセルを直接編集してリグへ書き込めます。誤編集防止のため、普段はチェックを入れたままにしてください。
- **Select Memory Mode**: リグをメモリーモードに切り替えてチャンネルを呼び出します。もう一度押すと VFO モードへ戻ります。
- **Start Scan**: メモリースキャンを開始します（対応機のみ）。
- **.csv Import / .csv Export**: メモリー内容を CSV ファイルで書き出し・読み込みできます。PC で一括編集して書き戻す、バックアップを取る、といった使い方ができます。
- **「← 戻る」** でメイン画面へ戻ります。

## 12. CW 送信（CW）

**CW** ボタンで開きます（CW キーイング対応機のみ有効）。キーボードから CW（モールス）を送出できます。

### 12-1. 基本の送信

1. モードを **CW**（または CW-R）にします。
2. **Text to Send** に送りたい文字列（例: `CQ CQ CQ DE JA6FUF JA6FUF K`）を入力します。
3. **Send**（または改行キー）で送出開始、**Stop** でいつでも中止できます。
4. **Send Immed** をオンにすると、Enter を待たず**タイプした端から**送出します（ラバースタンプ QSO のリアルタイム打鍵向け）。

### 12-2. 各種設定

| 項目 | 内容 |
|------|------|
| **WPM** | 送信速度（Words Per Minute）。ゆっくりなら 15 前後、通常 20〜25 |
| **PITCH (Hz)** | CW の受信トーン周波数（600〜700 Hz が一般的） |
| **Dash Ratio** | 長点の長さの比率（標準 3.0） |
| **Break In** | **Off**＝手動で PTT、**Semi**＝送出開始で自動送信・終了で受信、**Full**＝符号の間も受信するフルブレークイン |
| **Cut Num** | 数字の短縮符号化（9→N、0→T など）。コンテスト向け |
| **Macros** | 定型文（CQ 呼出し、599 レポート等）をボタンに登録してワンタップ送出 |
| **Enable Local Sidetone ＋ Level** | 手元（iPad 側）でサイドトーンを鳴らします。ネットワーク遅延の影響を受けずに打鍵音を確認できます |

- CW デコード対応機では **Received Text** 欄に受信解読文が、**Transmission Transcript** に送信済みテキストが表示されます。

## 13. TX Proc / RX Proc（送受信音声処理）

ネットワーク経由の音声に対して、iPad 側で追加の音声処理ができます。

### 13-1. TX Proc（送信音声）

マイク音声に対する処理チェーンを設定します。

- **コンプレッサー**: 平均電力を上げて了解度を改善。
- **イコライザー**: 低域を削って中高域を持ち上げると、DX 向けの「通る」音になります。
- **ノイズゲート**: 無音時の環境音をカット。
- 効き具合は **Mon** スライダーで自分の送信音を聞きながら調整するのが確実です。

### 13-2. RX Proc（受信音声）

受信音に対する処理を設定します。

- **ノイズリダクション**: リグ側の NR と併用できます。まずリグ側 NR、足りなければこちらを追加する順がおすすめです。
- **イコライザー**: 聞き疲れしにくい音に調整できます。

どちらも固定サイズ（1000×760）のオーバーレイで開き、収まらない項目は画面内でスクロールします。設定は保存され、次回接続時も有効です。

## 14. 無線機の基本機能ガイド（モードの選び方）

| モード | 主な用途 |
|--------|----------|
| **USB**（上側波帯） | 10 MHz 以上（14/21/28/50 MHz 帯）の音声通信。HF ハイバンドの標準 |
| **LSB**（下側波帯） | 7 MHz 以下（1.9/3.5/7 MHz 帯）の音声通信 |
| **CW / CW-R** | モールス通信。狭帯域で弱い信号・遠距離に強い。CW-R は逆サイドバンドで混信回避 |
| **AM** | 放送受信や一部の音声通信。帯域が広く音質は良いが混信に弱い |
| **FM** | 29/50/144/430 MHz 帯の近距離・レピータ運用。音質良好 |
| **RTTY / RTTY-R** | 無線テレタイプ（FSK） |
| **USB-D / LSB-D 等**（データ） | FT8・PSK など PC を使うデジタルモード。変調入力が外部音声になります |

**フィルター（FIL1/2/3）の使い分け**: 混信が多いときは狭いフィルター、音質を重視するときは広いフィルターを選びます。CW では 500 Hz 以下の狭帯域が定番です。

**AGC**: 受信音量を自動で一定に保つ機能です。目安は CW=FAST、SSB=MID〜SLOW。

## 15. 基本操作の流れ（クイックスタート）

1. **Settings → Radio Access** で接続先を入力し、プロファイルに保存（初回のみ）。
2. **Connect** で接続。リグ名が表示され、コントロールが現れるのを待つ。
3. （リグが休止中なら）**Power On** で電源投入。
4. **Bands** でバンドを選び、**ウォーターフォールをタップ**して信号に同調。桁タップ＋ダイアル（必要なら **Fine**）で追い込む。
5. **AF**（音量）と **SQ**（スケルチ）を調整して受信音を整える。ノイズが多ければ **NR / NB** を試す。
6. 送信前に **TUNE** で ATU を整合（SWR メーターで確認）。
7. **送信** ボタンでオンエア。**MOD**（変調レベル）と **Mon** で変調を確認。
8. 運用が終わったら **Disconnect from Radio** → 必要なら **Power Off**。

## 16. こんなときは（トラブルシューティング）

| 症状 | 確認すること |
|------|--------------|
| アプリが起動しなくなった | 無料署名の 7 日失効。Mac から再インストール |
| 接続できない | ホスト IP／ポート／ユーザー名・パスワード。リグまたは wfserver が動いているか。iPad が同じ Wi-Fi にいるか。ローカルネットワーク許可（iPadOS 設定 → プライバシー） |
| 接続はできるが音が出ない | AF スライダー、SQ の開き具合、iPad 本体の音量。Settings → Radio Access の RX Audio コーデック設定 |
| 音が途切れる | Wi-Fi の電波状態。RX Audio のサンプルレートを下げる／Opus 系コーデックにする |
| 送信できない・変調が浅い | MOD スライダー、TX Proc の設定、Settings の TX Audio 入力、iPad のマイク権限 |
| TUNE が失敗する | Other Controls の **Tune（Enable ATU）** がオンか。アンテナが繋がっているか |
| 画面のボタンが少ない | リグ未検出。接続完了までお待ちください（機種非対応の機能は表示されません） |
| 周波数が変えられない | **Lock** がオンになっていないか |
| 意図せず周波数が動く | **Lock** をオンにして誤タッチを防止 |
| スプリットのまま戻せない | Rpt/Split 画面で **Split Off**、レピータ設定は **Simplex** を選択 |
| メモリー一覧が空 | 読み込みに時間がかかることがあります。グループ選択を切り替えてみてください |

## 17. 注意事項

### マイク入力について

- 送信の変調には**マイク権限**が必要です。初回起動時のダイアログで「許可」を選んでください（拒否した場合は Android の設定 → アプリ → wfview → 権限 から変更できます）。
- **マイク入力は「Built in microphone（内蔵マイク）」を推奨**します。Bluetooth イヤホンのマイクは Android の録音経路（SCO）に未対応のため、現状は音声が取れません（受信音の Bluetooth 再生は問題ありません）。
- 内蔵マイクの生レベルが低いため、アプリ内で約 6 倍のブーストをかけています。Tx(dBfs) メーターを見ながら、必要に応じて **MOD** スライダーで調整してください。
- 「受信音出力」「マイク入力」の選択は変更した時点で保存され、次回起動時も維持されます。

- 送信を伴う操作（送信・TUNE・CW 送出）は、周波数・電力・アンテナ・免許範囲を確認のうえ自己責任で行ってください。電波の発射は各国の電波法令の範囲内で行ってください。
- メモリー編集は実験的機能です。必ずリグのバックアップを取ってから操作してください。
- 本アプリはシリアル／USB 接続に非対応です。**ネットワーク接続専用**です。
- 本アプリはデスクトップ版 wfview（GPLv3）を Android タブレット向けに再構成したものです。細部の挙動は本家 wfview に準じます。本家の情報は <https://wfview.org/> を参照してください。
